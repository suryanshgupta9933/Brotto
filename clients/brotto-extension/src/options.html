Automation Settings

Permission Justification

debugger
Required to use chrome.debugger API for controlling browser tabs. This is the core mechanism for browser automation - it allows taking screenshots, executing mouse/keyboard actions, and navigating pages. Without this, the extension cannot automate browser tasks.
activeTab
Allows the extension to access the currently active tab when the user invokes the extension. This is needed to display the tab selection dialog and to attach the debugger to the user-selected tab.
tabs
Required to list available tabs for selection. The extension needs to show users which tabs they can automate. Tab titles and URLs are displayed in the selection dialog.
tabGroups
Allows the extension to work with Chrome tab groups. Users can select an entire tab group for automation, and the extension manages the group during the automation session.
<all_urls>
Required because users may want to automate any website. The extension does NOT automatically access all sites - it only attaches to tabs explicitly selected by the user after confirmation. This is a standard permission for debugger extensions.
